# Meu Projeto AI Studio

Este é um projeto web desenvolvido com **React**, **Vite** e **TypeScript**, rodando com um backend em **Express** (arquitetura Fullstack).

## Estrutura do Projeto

* `src/`: Código fonte frontend (componentes, serviços, etc).
* `server.ts`: Servidor backend Node.js.
* `public/`: Assets estáticos.

## Como Rodar

```bash
npm run dev
```
